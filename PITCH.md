**0:00 – 0:10 | Cold open**
Load the live player: https://nithin-alaska--repo-radio-serve-fastapi-app.modal.run — already sitting on ep-001. Hit play immediately, no setup talk.
> "This is Repo Radio. Every day it picks whatever repo is blowing up fastest on GitHub right now — and reads the actual code, not the README."

**0:10 – 0:30 | The karaoke/citation moment**
Let the host talk over the waveform. As the transcript line glows and auto-scrolls, point at the code card flipping to the cited file and highlighting the exact lines.
> "Watch this — every sentence it says is tied to a real file, a real line range. It's not summarizing the README. It opened the source."

**0:30 – 0:55 | The Fuxi HYPE reveal — the story beat**
Let the verdict badge (HYPE, red) sit on screen.

And the benchmark folder its own scripts point at? Hardcoded to a directory literally named 'Fuxi-github-promo.' The code just... told on itself."

**0:55 – 1:10 | Wallet ask flow**
Scroll to the "CALL THE SHOW" strip.
> "Got a question about the repo? A dollar buys ten questions, answered on air, same citation treatment." *(type a question, show credit tick down, new segment plays with its own citation)*

**1:10 – 1:20 | Memory panel**
Open the Host's Memory sidebar.
> "And it remembers. Next AI-agent repo that trends, the host calls back to Fuxi by name — 'previously on Repo Radio.' That's claude-mem giving this thing continuity across episodes."

**1:20 – 1:30 | Closing one-liner**
Cut back to the player, verdict badge visible.
> "Repo Radio: we read the code so you don't have to."
